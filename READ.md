## Reason it runs on C++ setup mostly 

* **Speed and Performance:** Critical for processing high-frequency market data and exercuting trades instantly.

* **Low-Level Control:** Allows precise memory management and optimized mathematical computations.

* **Reliability:** Strict compile-time checks help catch syntax and logic bugs early before they impact the live execution.

-------------------------------------------------------------------------

## Why is Python for playing it's part
   
* **Rapid Prototyping:** Allows for fast strategy iteration, quick testing of trading hypotheses, and agile script development deployment

* **Data Science Ecosystem:** Leverages powerful libraries (such as Numpy, Pandas, and Matplotlib) for historical date manipulation, vectorization, statistical analysis, and equity curve visualization.

* **API & Ecosystem Integration:** Simplifies connecting to broker APIs, data feeds, and external tools with minimal boilerplate code.
